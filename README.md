# Darun Portfolio

Editorial technical portfolio for Darun Prasath Ramalingam, featuring experience, selected systems, capabilities, foundation, and contact information.

## Stack

Next.js, React, TypeScript, and Lucide React.

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
pnpm lint
pnpm build
```

Portfolio content is maintained in `src/data/portfolio.ts`.
